# SBA 316: The Document Object Model

## Birthday Reminder Application

## Purpose of this application is to add a list of birthdays 


## Dependencies:

User needs to have any browser in their laptops

## Installing:
Fork and clone the files to your computer

## Authors
Sinchana Rai

## Technologies used:
- HTML
- CSS
- Javascript

## Application Function

1. User can add a list of bithdays by filling in Name and Date of birth fields
2. User can edit an added item from the list of items by clicking edit button. 
    - User can edit the Name in the prompt at the top of the webpage
    - User can edit the Date in the prompt at the top of the webpage
3. User can delete an added item from the list of items by clicking delete button.
4. User can change the background color by clicking on the dropdown at the top of the webpage
